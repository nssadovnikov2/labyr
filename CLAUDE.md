# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Пошаговая браузерная игра-лабиринт по мотивам FNAF. Правила, предметы, сложности и
описание ночей — в `README.md`; замысел, режиссура и открытые вопросы — в `DESIGN.md`;
здесь только то, что нужно для работы с кодом.
Комментарии, интерфейс и коммиты в проекте на русском.

Перед тем как трогать баланс, звук или интерфейс, прочитайте `DESIGN.md`: там записано,
почему числа именно такие и какую поломку каждый клапан закрывает.

## Команды

Сборки нет — чистые ES-модули без зависимостей. Но `file://` не годится, модулям нужен HTTP:

```bash
python3 -m http.server 8123
```

Тестов нет. Проверка синтаксиса модуля:

```bash
node --check src/game.js
```

Деплой: GitHub Pages раздаёт ветку `main` из корня, `.nojekyll` отключает Jekyll.
Достаточно `git push` — отдельного шага сборки нет.

```bash
gh api repos/nssadovnikov2/labyr/pages/builds/latest --jq .status
```

## Архитектура

**`Game` (`src/game.js`) не знает про DOM.** Ни канваса, ни элементов — только состояние
партии и события. Отсюда два следствия: игру можно целиком прогнать в Node (см. «Баланс»),
а всю связку с интерфейсом держит `main.js`, подписываясь на события:
`state` (перерисовать HUD), `step`, `bump`, `pickup`, `use`, `dodge`, `toast`,
`phase`, `death`, `win`.

**Фазы партии:** `player` → `ai` → `player`. Ход аниматроников асинхронный
(`_aiTurn` с `await sleep`), поэтому при замене партии обязателен `game.abort()` —
иначе старый цикл досчитает ход и начнёт слать события поверх новой игры.

**ИИ решает раз в ход, ходит несколько раз.** `_aiPlan(a)` выбирает режим и цель один
раз за ход, `_stepAi(a)` вызывается `speed` раз и просто спускается по полю расстояний
к цели. Режимы: `hunt` (прямо на игрока), `flank` (перехват на пути к выходу),
`search` (последнее известное место), `stalk` (идёт в район игрока, пока сокращает
разрыв), `patrol` (случайная точка или окрестность выхода). Хотя бы один аниматроник
всегда идёт в лоб — если резать путь будут все, гнаться станет некому и игрока не поймают.

**Лабиринт — идеальный (recursive backtracker), связность гарантирована по построению**,
поэтому путь до выхода существует всегда и проверять это не нужно. `braid` вскрывает часть
тупиков и добавляет петли. Вся навигация — волновой поиск из `src/maze.js`:
`bfsDist` (поле расстояний), `findPath` (спуск по полю), `fieldOfView` (обзор сквозь стены).
Сетка хранится битовой маской стен в `Uint8Array`, направления — `1/2/4/8`.

**Отрисовка гибридная.** Лабиринт рисуется на канвасе, а игрок и аниматроники — это
DOM-элементы с графикой на чистом CSS (`styles/entities.css`), которые `Renderer`
позиционирует каждый кадр. `font-size` элемента равен размеру клетки, вся фигурка внутри
свёрстана в `em` — поэтому она масштабируется сама. Камера всегда центрируется на игроке;
за краем лабиринта просто чернота.

**Страх связывает половину систем.** `game.fear` (0..1) считается от дистанции до
ближайшего аниматроника и от того, виден ли он. От него зависят: наезд камеры и
тоннельная виньетка (`render.js`), четвёртый шаг в ходу (`stepsPerTurn`), дрожь героя
(CSS-класс `scared`/`terrified`), плотность атмосферных звуков (`main.js: tension()`).
Любой подобранный предмет обнуляет страх и даёт `calm` ходов передышки.

**Звук синтезируется целиком, файлов нет.** `Sfx` владеет `AudioContext`, мастер-громкостью
и общим ревербератором; `Music` подключается к `sfx.master` и `sfx.verb`, поэтому музыка
и звуки звучат в одном помещении. Аудиоконтекст не существует до первого жеста пользователя —
всё аудио поднимается из `wakeAudio()`. Голоса музыки разведены по шинам
(`boxGain` / `guitarGain` / `bassGain`), уровни атмосферы — таблица `LVL` в `src/audio.js`;
узкополосные фильтры съедают энергию, поэтому у каждого звука свой множитель.

**Тема музыки — набор настроек, а не ноты.** `PRESETS` в `src/music.js` задаёт круг
аккордов, размер, темп, плотность, долю хроматики и количество перкуссии; ноты
собираются заново каждый такт. Секвенсор планирует такты вперёд по `ctx.currentTime`,
а не по таймеру.

**Прохождение** (`src/campaign.js`): ID лабиринта каждой ночи зашит (`nightSeed`),
поэтому карта ночи неизменна. `nightSettings` кладёт конфиг ночи поверх пользовательских
предпочтений — размер, число аниматроников и сложность идут от ночи, масштаб и звук от игрока.

## Грабли, на которые уже наступали

- **`[hidden]` не работает без `!important`**: `.overlay { display: flex }` перебивает
  атрибут по специфичности. Правило есть в `base.css`, не удалять.
- **Дефолты чекбоксов должны стоять в разметке** (`checked`). Форма настроек читается
  напрямую из DOM; если `writeForm` ещё не отработал, а форму прочитали, сохранится
  «всё выключено» — и это уедет в localStorage.
- **`input[type="range"]` сильнее одиночного класса.** Переопределять только через
  `.player .pvol` и подобное.
- **`requestAnimationFrame` не тикает в фоновой вкладке.** Проверяя рендер из консоли
  или автоматикой, вызывайте `LABYR.renderer.frame()` вручную в цикле, иначе камера
  и зум «не реагируют».
- **Автоповтор клавиши игнорируется** (`e.repeat`) — игра пошаговая, иначе ходы улетают
  пачками. Клавиши также не перехватываются, когда фокус в поле ввода (ползунок громкости).
- **Устаревшие значения в localStorage надо мигрировать.** Ключи `labyr.settings.v1` и
  `labyr.campaign.v1`. Пример в `main.js`: исчезнувшая сложность молча переводится на
  нижнюю ступень, иначе селект остаётся пустым, а `DIFFICULTY[...]` — undefined.
- **Шрифты грузятся с Google Fonts**, остальное самодостаточно.

## Баланс

Балансировка проверяется прогоном партий в Node, а не на глаз: `Game` работает без DOM.
Скрипт одноразовый, в репозиторий не коммитится:

```js
// sim.mjs — node sim.mjs
import { Game } from './src/game.js';
const S = { fog:true, fogRadius:6, ai:2, difficulty:'nightmare', size:100, braid:40,
  itemDensity:0.01, exitAt:'other', zoom:'mid', sound:false, volume:0, ambience:false,
  music:false, musicVolume:0, musicTheme:'box', fearFx:true, seed:'' };
const g = new Game(S);
g.aiStepDelay = 0;                       // иначе ход ИИ ждёт реального времени
while (g.phase !== 'dead' && g.phase !== 'win') {
  if (g.phase !== 'player') { await new Promise(r => setImmediate(r)); continue; }
  // ...ход бота: g.move(dir) / g.endTurn()
}
console.log(g.phase, g.turn);
```

Что мерить: доля партий без единой встречи, ходов рядом с аниматроником, доля смертей.
Одна партия ничего не говорит — нужны десятки, разброс от расклада огромный.
Ручки: `DIFFICULTY` в `game.js` (`sense`, `speed`, `patience`, `flank`, `dodgeCd`, `stun`,
`adrenaline`), `NIGHTS` в `campaign.js`, `DEFAULTS` в `settings.js`.

## Отладка из браузера

`window.LABYR` открывает `game`, `renderer`, `settings`, `sfx`, `music` и `start`.
Уровни звука правятся вживую: `LABYR.music.boxGain.gain.value = 0.4`.
Аудио появляется только после первого жеста — сначала начните партию.
